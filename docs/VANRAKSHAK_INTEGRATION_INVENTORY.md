## 4. SCIENTIFIC ETHICS & INTEGRITY DISCLOSURES

1. **No Data Fabrication**: Where a satellite sensor cannot penetrate cloud cover and no SAR or fallback exists, the system states `DATA_UNAVAILABLE` rather than hallucinating vegetation numbers.
2. **Provenance Preservation**: All data payloads returned to the frontend contain `provenance` metadata detailing `source`, `freshness`, `url`, and `retrieved_at`.
3. **Model Output vs. Satellite Observation**: The UI strictly distinguishes between **Direct Spacecraft Measurements** (Sentinel-2, Landsat, MODIS, GEDI), **Reanalysis Models** (MERRA-2, ERA5, NASA POWER), and **AI Diagnostic Estimates** (Forest Doctor, Threat Cascade).
